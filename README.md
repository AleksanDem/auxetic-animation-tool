# 🧬 Параметрический генератор анимаций ауксетиков (Streamlit)
**Капсула проекта:** `PHD_0826_Dissertation`  
**Автор исследования:** Демин Александр Иванович (ИПМех РАН)

Интерактивное веб-приложение для параметрической генерации презентационных и публикационных анимаций (GIF / MP4) в механике метаматериалов и сплошных сред.

---

## 🎯 Реализованные фундаментальные сценарии
1. **Одноосное растяжение / сжатие:**
   - Сравнение классического материала ($\nu > 0$) и ауксетика ($\nu < 0$);
   - Режимы континуумной деформируемой сетки и микроструктурных ячеек RVE (Regular Honeycomb vs Re-entrant Honeycomb);
   - Динамические векторные стрелки растягивающих сил и поперечного отклика.
2. **3D-изгиб пластин (Купол vs Седло):**
   - Синкластический изгиб (купол/сферическая чаша при $\nu < 0$);
   - Антикластический изгиб (седло при $\nu > 0$);
   - Управление 3D-ракурсом камеры (elevation, azimuth), масштаб кривизны.
3. **Контактное индентирование полупространства (Самоуплотнение):**
   - Аналитическая модель контактного поля Буссинеска;
   - Эффект поперечного стягивания массы и динамического запирания при $\nu < 0$;
   - Различные формы индентора (скругленный, плоский штамп, конический);
   - Векторное поле перемещений узлов (Quiver) и карта локальной плотности.

---

## 🛠️ Возможности генератора
- **Форматы холста:** 16:9 Widescreen (презентации), 4:3, 1:1 (квадрат для статей), пользовательский размер и DPI;
- **Компоновки панелей:** 1 панель, 2 Side-by-Side (горизонтально), 2 Top/Bottom (вертикально), сетка 2x2, Ghost Overlay (наложение);
- **Управление параметрами:** независимые слайдеры коэффициента Пуассона $\nu \in [-2.5, +1.5]$, масштабный множитель перемещений $k_{\text{disp}}$, FPS, число кадров и фазы удержания;
- **Академические стили:** Blue-Orange (канонический стиль конференции Мясникова), Emerald-Amber, Monochrome (для печати ВАК), Dark Sci-Fi;
- **Экспорт:** зацикленный оптимизированный GIF (Pillow + двухпроходный FFmpeg palettegen) и MP4 (кодек H.264, профиль High, yuv420p для 100% совместимости с PowerPoint).

---

## 🚀 Быстрый запуск
Для запуска локального сервера Streamlit выполните в терминале из директории генератора:
```powershell
streamlit run app.py
```
или из корня репозитория:
```powershell
streamlit run 05_src/04_Animation_Generator/app.py
```

Приложение автоматически откроется в браузере по адресу `http://localhost:8501`.
